En forfragning racker

Skicka ett POST-anrop med din anvandares namn. Fa tillbaka en URL och en QR-kod som anvandaren skannar for att verifiera sig.

Skapa en verifiering cURL 
curl -X POST https://felai.se/api/verify \
  -H "Authorization: Bearer DIN_API_NYCKEL" \
  -H "Content-Type: application/json" \
  -d '{"name": "Anna Svensson"}'
Svar JSON 
{
  "id": "a3f8c2d1e4b5",
  "status": "pending",
  "verify_url": "https://felai.se/verify/a3f8c2d1e4b5",
  "code": "KXMP4",
  "sms_number": "+46700123456"
}

Visa verify_url for din anvandare — eller generera en QR-kod fran den. Nar anvandaren skickar SMS-koden uppdateras statusen till "verified".
